# List of Our Original Header (.h) files 

- [app.h](./app.h) - Application Layer header with important declarations 
- [step_update.h](./step_update.h) - IMU read for new number of steps (run only on interrupt flag raised)
- [buzzer.h](./buzzer.h) - buzzer library and output control
- [adc_interface.h](./adc_interface.h) - Potentiometer and Joystick ADC reading
- [display.h](./display.h) - Display OLED output control
- [progress_leds.h](./progress_leds.h) - RGBLED output control
- [button.h](./button.h) - Button input control
- [number_processing.h](./number_processing.h) - number processor helper
- [timing.h](./timing.h) - Timing functionality
- [uart.h](./uart.h) - UART debug helper control
