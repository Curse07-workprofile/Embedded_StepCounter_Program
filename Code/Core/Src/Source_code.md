# List of Our Original Source (.c) files 

- [app.c](./app.c) - Application Layer
- [step_update.c](./step_update.c) - IMU read for new number of steps (run only on interrupt flag raised)
- [buzzer.c](./buzzer.c) - buzzer library and output control
- [adc_interface.c](./adc_interface.c) - Potentiometer and Joystick ADC reading
- [display.c](./display.c) - Display OLED output control
- [progress_leds.c](./progress_leds.c) - RGBLED output control
- [button.c](./button.c) - Button input control
- [number_processing.c](./number_processing.c) - number processor helper
- [timing.c](./timing.c) - Timing functionality
- [uart.c](./uart.c) - UART debug helper control
